## ⚡ Visão Geral

📐 CAD Web 2D/3D - Visualizador e Ferramenta de Desenho Técnico e Plantas no Navegador. Desenvolvido com foco em alta performance, usabilidade moderna e arquitetura web escalável.

### 🌟 Principais Recursos:
* Ferramentas de desenho vetorial para engenharia e arquitetura
* Controle de camadas, cotas e medidas em escala
* Extensão de produtividade para o navegador
* Exportação em formatos vetoriais e imagens
